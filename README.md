# Cardanz Releases

Distribuzione pubblica ufficiale dell'app Android Cardanz.

- La pagina di download si trova in `site/index.html`.
- I metadati dell'ultima versione si trovano in `site/update.json`.
- Gli APK firmati sono pubblicati esclusivamente come asset delle GitHub Release e non sono tracciati da Git.

Release corrente: [Cardanz 1.0.0](https://github.com/cgcicca/Cardanz-Releases/releases/tag/v1.0.0).
